World in One Day draws a newspaper front page summarizing the world news of Wednesday 25 November 2026 as a single 1024 x 1024 PNG: China's Shenzhou-24 launches with the first Pakistani astronaut to Tiangong, Dutch climate targets stay binding, Australia signs a Pacific security pact with the Solomon Islands, Bangladesh raises garment wages 36%, Asian tech shares slide, the coalition strikes Hodeidah overnight, the EU and Canada team up on AI, and the Pope applies for a US mail-in ballot. It uses only the Python 3.13 standard library — the PNG encoder and the type are hand-rolled in main.py.

News sources checked on 25 November 2026: Xinhua, Reuters, AP, NOS, TBS News, AFP, Al Jazeera, The Munich Eye.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is `out/entry.png`.
